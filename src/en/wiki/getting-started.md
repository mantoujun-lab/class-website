# Getting Started

Welcome! This guide shows you how to contribute to the class website.

## How to Contribute an Article

1. Fork the repo
2. Create a file at `src/event-<date>.md`
3. Submit a PR
4. Wait for review and approval, then auto-deploy

## How to Contribute to the Wiki

Similar to writing an article — just create or edit a `.md` file under `src/wiki/`.

## Notes

- Add a space between Chinese and English
- Upload images to `src/assets/images/`
- Run a local build to verify before submitting
