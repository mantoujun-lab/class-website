# Contribution Workflow

1. Fork the repo
2. Create a new file at `src/en/wiki/<category>/xxx.md`
3. Submit a PR

## Notes

- The content between `<!-- CONTRIBUTORS START/END -->` in the contributors avatar wall (`README.md` / `src/zh-cn/index.md` / `src/en/index.md`) is auto-generated by GitHub Actions — **do not edit manually**, or it will be overwritten the next time the Action runs
- Avatars are pulled automatically by GitHub, no manual sync needed
## Commit Identity Guidelines

- Before committing, make sure your Git identity matches your GitHub account:

  ```bash
  git config user.name "Your GitHub username"
  git config user.email "12345678+username@users.noreply.github.com"   # your GitHub noreply email
  ```

- **When an AI coding assistant (Trae / Copilot, etc.) commits on your behalf**, use your real identity or your GitHub noreply email — never fake addresses like `xxx@example.com`, otherwise contributor statistics get split and commits become untraceable.
- The `.mailmap` at the repo root already unifies historical aliases (e.g. "一张白纸" / "一张黑纸") and fake emails; verify with `git shortlog -sne`.
