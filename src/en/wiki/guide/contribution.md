# Contribution Workflow

1. Fork the repo
2. Create a new file at `src/en/wiki/<category>/xxx.md`
3. Submit a PR

## Notes

- The content between `<!-- CONTRIBUTORS START/END -->` in the contributors avatar wall (`README.md` / `src/zh-cn/index.md` / `src/en/index.md`) is auto-generated by GitHub Actions — **do not edit manually**, or it will be overwritten the next time the Action runs
- Avatars are pulled automatically by GitHub, no manual sync needed
